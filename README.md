# แดชบอร์ดติดตาม DMC — สพม.ชัยภูมิ

เว็บหน้าเดียวสำหรับติดตามสถานะการยืนยัน/รับรองข้อมูลนักเรียนรายบุคคล (DMC) ของ 37 โรงเรียนใน สพม.ชัยภูมิ
อ่านข้อมูลสดจาก Google Sheet ด้วย `gviz/tq?tqx=out:csv` — ไม่มีเซิร์ฟเวอร์ ไม่มี build step ไม่มี GitHub Action

- หน้าเว็บ: https://cobio123.github.io/dmc-spmcp-dashboard/
- ข้อกำหนดตรวจรับ: [SPEC.md](SPEC.md)

## การใช้งานประจำรอบ

1. คัดลอกจากหน้า "สถานะการยืนยันข้อมูลของโรงเรียนในเขต" ในระบบ DMC มาวางในแท็บ `data` (วางทับทั้งบล็อกได้เลย)
2. พิมพ์วันเวลาของข้อมูลในแท็บ `meta` ช่อง A1 รูปแบบ `2026-11-10 14:30` (หรือข้อความไทย "ข้อมูล ณ วันที่ 10 พฤศจิกายน 2569 เวลา 14.30 น." ก็อ่านได้)
3. แชร์ชีท: **ทุกคนที่มีลิงก์ → ผู้ชม** (หน้าเว็บอ่านได้เฉพาะชีทที่แชร์แบบนี้)

## ขึ้นรอบใหม่ (เช่น 1/2570, รอบสิ้นปี)

1. `File → Make a copy` ของชีทเดิม (ชื่อแท็บ `data` / `meta` ติดมาด้วย)
2. แก้ `docs/config.js` **ไฟล์เดียว**: `sheetId`, `roundName`, `dataNote`, `deadline`
3. commit + push — GitHub Pages อัปเดตเองภายใน 1 นาที

## ลิงก์เฉพาะโรงเรียน

`?school=<รหัส 8 หลัก>` เช่น `?school=36012001` — หรือกดปุ่ม "คัดลอกลิงก์" ท้ายแถวของแต่ละโรงเรียน

## ข้อจำกัดที่ควรรู้

- Google แคช CSV ราว 1–5 นาที หลังวางข้อมูลใหม่
- ถ้าย้าย/ก๊อปชีท ต้องอัปเดต `SHEET_ID` ไม่งั้นหน้าเว็บจะขึ้นข้อความแจ้งเตือน (ไม่ใช่หน้าจอว่าง)
- หน้าเว็บเป็น public: แสดงเฉพาะสถานะรวมระดับโรงเรียน ไม่มีข้อมูลนักเรียนรายคน

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `docs/index.html` | โครงหน้า |
